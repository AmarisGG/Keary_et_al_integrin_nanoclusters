# Appendix 1 – Figure 1

This folder contains the source code and source data used to generate the STED fluorescence-intensity profiles shown in Appendix 1 – Figure 1.

## Files

- `Appendix1_Figure1_SourceCode1.m`  
  MATLAB script used to generate the fluorescence-intensity line profiles.

- `Appendix1_Figure1_SourceData1.xlsx`  
  Source data containing distance and fluorescence-intensity values.

## Analysis

The MATLAB script generates individual fluorescence-intensity profiles for:

- α5 integrin
- active β1 integrin (9EG7)
- αVβ3 integrin
- paxillin

For each marker, profiles corresponding to Glass, noFA, and FA regions are plotted directly from the source-data workbook.

No smoothing or normalization is applied.

## Software

MATLAB (MathWorks).
