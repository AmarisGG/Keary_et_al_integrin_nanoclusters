# Keary et al. – Differential spatial regulation and activation of integrin nanoclusters inside focal adhesions

This repository contains source code and associated source data used for quantitative image analysis and figure generation in https://doi.org/10.7554/eLife.105270.2

The repository is organized by figure:

- `Appendix1_Figure1`  
  STED fluorescence-intensity line-profile analysis.

- `Appendix1_Figure2`  
  Fiji/ImageJ and MATLAB analysis of radial fluorescence profiles and focal-adhesion edge enrichment.

- `Appendix2_Figure1`  
  MATLAB DBSCAN analysis of DNA-PAINT nanoclusters.

Each folder contains the corresponding source code, source data, and a dedicated README with analysis details.

## Software

- MATLAB (MathWorks)
- Fiji/ImageJ

## Data availability

Processed source data required to reproduce the analyses included in this repository are provided together with the corresponding code.

Additional experimental and raw data associated with the study are available through the data repository linked to the publication.
